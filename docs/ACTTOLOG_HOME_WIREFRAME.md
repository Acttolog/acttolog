## 04 — Division portals

```text
RESEARCH LAB     ACADEMY          GAMES WORLD
ENTERTAINMENT    DARKROOM

Each portal:
- canonical division name
- one-line purpose
- real count from registry
- direct route
- preview / focus state
- return to atrium
```

Additional destinations (Nepal, World, Loksewa, Blog, Offers, AI) are quick links, not artificial major divisions.
